## 🚀 Overview

A structured **beginner → intermediate journey into NumPy**, designed for:

- 🤖 Artificial Intelligence  
- 📊 Data Science  
- ⚡ High-Performance Computing  

This repository contains **4 carefully designed notebooks** focused on:
- Strong fundamentals  
- Visual intuition  
- Performance thinking  

---

## 📌 Why This Series?

Most tutorials teach NumPy as syntax.  
This one focuses on:

- ⚡ Performance (vectorization mindset)  
- 🧠 Deep intuition (how arrays actually work)  
- 🤖 AI relevance (NumPy in ML)  

---

## 📚 Notebook Roadmap

### 🧩 1. Arrays & Fundamentals
- 1D, 2D, nD arrays  
- Data types (`dtype`)  
- Indexing & slicing  
- Memory efficiency  

👉 **Outcome:** Understand NumPy under the hood  

---

### ⚡ 2. Vectorization & Performance
- Loops vs Vectorization 🐢 vs ⚡  
- Broadcasting  
- Why NumPy is fast (C backend)  

👉 **Outcome:** Stop writing slow loops  

---

### 🔄 3. Core Operations & Manipulation
- Reshaping arrays  
- Stacking & splitting  
- Mathematical operations  
- Aggregations (`sum`, `mean`)  

👉 **Outcome:** Manipulate data like a pro  

---

### 🤖 4. NumPy for AI
- Linear algebra basics  
- Matrix multiplication  
- ML-style computations  
- Data preparation  

👉 **Outcome:** Connect NumPy → AI
